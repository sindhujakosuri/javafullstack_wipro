# Certificate webpage

This folder contains:
- `index.html` — webpage that displays the certificate
- `certificate.png` — image rendered from the uploaded PDF certificate

## Run locally
Keep both files in the same folder, then open `index.html` in a web browser.

## Upload to GitHub
1. Create a GitHub repository.
2. Upload `index.html` and `certificate.png` (or upload this ZIP and extract it first).
3. Open `index.html` in the repository, or enable GitHub Pages in Settings → Pages
   to publish the webpage.

The image path is relative (`certificate.png`), so keep the image in the same folder
as `index.html`.
